- Node 测试 48 项、Python 素材工具测试 14 项通过；生产依赖检查未发现已知漏洞。
- NSIS 安装程序在独立目录安装成功，退出码为 0；安装版实际播放韩立待机和阅读，加载 26 个人物下载项并打开修补窗口。

- 源码不包含个人配置、已安装人物、构建产物或原始素材；安装版只内置韩立。配置保存于用户 AppData，原帧与本地客户端配置保留。


2026-10-04：常用设置集中显示，逐帧、循环与统计收进「动画检查」，新增「回到待机」。默认启动不创建背景检查板，仍可手动打开；再次启动和托盘找回不会打开背景板。
