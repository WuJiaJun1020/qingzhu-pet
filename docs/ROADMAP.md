# 后续计划

## 1. 多人物资源包

- [ ] 用独立人物清单描述名称、预览、动画、尺寸和显示锚点。
- [ ] 在设置面板选择人物，切换时保留桌面位置。
- [ ] 校验资源尺寸、透明通道与文件完整性。
- [ ] 支持人物专属动作，并记录每套素材的来源和许可。

## 2. 扩充动作与交互

- [ ] 增加少量幅度小、可循环的待机动作。
- [ ] 增加思考、打坐、围棋等独立动作。
- [ ] 接入被拎起、悬停和松手落下的动画与交互状态。
- [ ] 改善不同动作首尾姿态、位置与节奏的衔接。
- [ ] 扩展双人互动，允许第二人物进入、互动与离开。

## 3. 调度、工具与发布

- [ ] 动作权重、冷却时间与用户触发条件。
- [ ] 可调节的画面边缘渐隐和净化参数。
- [ ] 素材导入界面与导入前预览。
- [ ] Windows 便携版或安装包。
- [ ] 将大体积动画资源与代码发布分离，支持按需下载。

以上为计划，不代表当前已经支持。当前版本使用一套韩立资源清单及五套动作。
