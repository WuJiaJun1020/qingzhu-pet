# 使用与素材导入

## 日常使用

默认不打开背景检查板，可在「动画检查」展开后手动打开。角色、大小、自动播放与动画控制放在主面板；逐帧、循环和触发统计位于可展开的「动画检查」。大小范围为 10%–100%，100% 按原素材像素显示，并适配 Windows 屏幕缩放。旧设置中超过 100% 的大小自动收敛到 100%。

默认播放待机；每次待机结束以可调概率触发当前人物的专属动作，默认 30%。0% 只播放待机，100% 每次待机后触发动作。被抓与下落仅通过拖拽触发。

所有动画统一使用净化透明帧，原始/净化对照开关已经移除。人物菜单只列出已安装人物。制作机器已有的八位人物保留，首次安装默认只附带韩立。

点击「人物资源」可下载其他人物，查看进度、取消或重试。下载包会校验总包和每个文件的 SHA-256，完整验证后才更新安装记录。安装完成后无需重启即可切换。安装资源位于 `数据/characters/`，安装后可离线使用。下载失败不影响已有的人物。

也可以从[公开发布页面](https://github.com/WuJiaJun1020/qingzhu-pet/releases/tag/characters-20261004)下载 `.qzpet`，再点击「从文件导入」。本地导入同样验证当前下载清单中的文件大小与哈希。

拖动产生移动时播放一次被抓动画，停住后自然保持尾帧，再移动才重播；松手播放下落并回到自身待机。角色可越过屏幕边界，通过「重新居中」或托盘「找回桌宠」找回。透明区域鼠标穿透，四周渐隐保持启用。

动画菜单进入手动检查模式，支持暂停、循环、逐帧与进度定位。重新勾选自动播放恢复随机调度。环境渐隐只在动作有环境遮罩时可选。

## 制作人员导入动画

`处理工具/import_animation.py` 接收已经去背景并完成校验的动画目录：

```text
任务信息.json          source、identity.sha256
render-report.json     source_sha256、frames、width、height、fps
验证结果.json          webm_decoded_frames、webm_alpha_max_error、png_archive_verified
透明PNG帧/             000001.png、000002.png……
```

源视频需仍然存在，以核对来源哈希；不能直接输入普通 MP4 或任意 PNG 文件夹。

```powershell
python .\处理工具\import_animation.py "已校验的透明动画输出目录" --id hanli-new --title "新动作" --character hanli
```

用 `--role idle` 添加待机，`--role interaction` 添加交互；默认是专属动作。`--character` 指定内置或已安装人物，省略则使用内置默认人物。替换已有动作加 `--replace`，同时保留旧文件与清单备份。

工具读取原 PNG、净化后直接另存无损 WebP，逐像素验证解码结果；发布目录只保留净化帧，不复制原始 PNG，不生成原始对照版本。相同帧按内容哈希共享文件。高透明度主体受到保护。输入视频与 PNG 不修改，导入记录和清单备份保存在 `数据/`。完成后重新启动读取修改后的清单。

## 生成独立人物包

```powershell
npm run pack:characters
```

输出位于 `release/build/`，包含内置默认人物资源、各人物 `.qzpet` 与下载清单。会读取内置人物及本地已安装人物，默认只处理实际存在的人物。打包不重新编码帧；包内仅净化无损 WebP。生成目录不直接覆盖当前客户端。发布前应更新 release tag、上传人物包并部署新的下载清单。

原始素材、历史备份、已安装人物、运行数据、下载临时文件和本地产物不提交 Git。`.qzpet` 属于透明动画资源，不是可执行文件。

`clean_alpha.py` 保留用于旧素材制作；已经净化的发布清单不接受重复净化，需从原始输出重新导入。`optimize_assets.py` 用于旧 PNG 的无损转换；新导入动作无需再转换。

```powershell
npm test
npm run test:python
npm run verify
npm run verify:download
```

最后一项访问公开 GitHub，其他检查可在资源齐全后离线运行；窗口验收使用隔离数据，不改变日常设置。制作主页 GIF 可运行 `python .\scripts\make-previews.py`，GIF 仅用于演示，不替代运行帧。
