# 使用与素材导入

## 日常使用

启动后，背景检查板默认打开，人物居中播放待机。面板中的概率滑块控制每次待机结束后触发其他动作的概率，默认 30%；0% 只播放待机，100% 每次待机后触发一个动作。随机队列每轮覆盖所有动作，动作结束回到待机。

拖动人物即可移动位置。透明区域鼠标穿透；画面四周以短边 8% 的宽度渐隐。拖动不限制桌面边界，可通过背景板「重新居中」、托盘「找回桌宠」或再次启动找回。

动画菜单进入手动检查模式，支持暂停、循环、进度定位和逐帧。重新勾选自动播放恢复待机与随机动作。净化开关用于对照原始透明帧和净化帧；环境渐隐开关仅在素材包含环境遮罩时启用，和始终启用的画面四边渐隐是两种处理。

## 导入透明动画

`处理工具/import_animation.py` 接收已经处理、校验过的透明动画输出目录，需要：

```text
任务信息.json          source、identity.sha256
render-report.json     source_sha256、frames、width、height、fps
验证结果.json          webm_decoded_frames、webm_alpha_max_error、png_archive_verified
透明PNG帧/             000001.png、000002.png……
```

这些是已有视频去白底工具的输出格式。源视频仍需存在以校验哈希。当前脚本不直接接收普通 MP4 或任意 PNG 文件夹。

```powershell
python .\处理工具\import_animation.py "已校验的透明动画输出目录" --id thinking --title "思考"
```

替换同一个动作时使用相同 ID 并加 `--replace`。脚本校验帧数与源文件哈希，保留原始帧，另存净化帧，备份清单后更新；替换时保留旧资源目录。完成后重新启动桌宠读取清单。

## 处理工具

- `clean_alpha.py`：通用低透明度杂色净化，保护高透明度主体和近邻边缘，另存至 `assets/cleaned-v1/`。
- `blend_edges.py`：使用外部主体遮罩降低环境边界的突兀感，当前纯人物动画不需要额外环境遮罩。
- `import_animation.py`：将校验过的透明动画导入清单，净化并保留源帧。
- `scripts/make-previews.py`：从有效清单的帧生成 README GIF，仅修改演示输出。

生成主页预览：

```powershell
python .\scripts\make-previews.py
```

PNG 是软件实际播放资源，GIF 是低帧率演示。不要用 GIF 替换程序的透明帧。
